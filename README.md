# boardgame-cafe-manager
A command-line system for a board game café. Staff can seat customers, lend out games, take food and drink orders, keep a running bill per table, and save sessions for returning guests.
This is a Python command-line app for running a board game café where games and food are tracked together, per table. Staff can look up the game and menu catalogue, add or remove items from a table's session, and mark each item as served: a game is checked out and later returned, while a food item is made once. The app shows an itemised bill that handles both game hire and food prices. It saves each table's session to CSV so a regular's favourite game can be picked up next time, and it suggests a table and game based on past visits. Built with plain Python only, with no outside libraries.
